# RIFT RUNNER (RR)

Браузерный arena survivor-roguelite в сеттинге разлома. Сейчас идёт **этап 0**: исследование и план. Код появится на этапе 1.

- `legacy/RR.html` — исходный однофайловый прототип (не изменяется)
- `docs/research/` — конспекты исследований, `SUMMARY.md` — ключевые формулы и числа
- `docs/legacy-audit.md` — что переносим из прототипа, что выбрасываем
- `docs/PLAN.md` — план по этапам и архитектура
- `.claude/skills/` — скиллы проекта (`game-balance`, `game-feel` и сторонние)
