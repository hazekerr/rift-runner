# game-balance: баланс RIFT RUNNER

Истина в последней инстанции: `docs/research/SUMMARY.md` (формулы и стартовые числа) и `src/content/balance.ts` (код). Если меняешь число, меняй оба места и `DESIGN.md`. Новое знание дописывай в `docs/research/01-balance-economy.md`.

## Каноничные формулы

```
waveTime(w)   = w==10 ? 45 : w==20 ? 60 : round(20 + 40(w-1)/19)
spawnRate(w)  = 1.0 + 0.22(w-1)                      // врагов/с, × Угроза
enemyHp(w)    = (1 + 0.30(w-1)) · 1.04^max(0,w-10)    // множитель
enemyDmg(w)   = 1 + 0.12(w-1)
price(b,w)    = floor(b · (1 + 0.10(w-1)))
reroll(w,n)   = ceil(1 + 0.5w) + n·max(1, floor(w/4))
xpToNext(L)   = round(8 · L^1.3)
armorMult(A)  = A>=0 ? 10/(10+A) : min(2, 2 - 10/(10-A))
dodge(D)      = min(60, D<=40 ? D : 40 + (D-40)/2)
atkSpd(S)     = S<=100 ? S : 100 + (S-100)/2 ; cooldown = max(0.05, base/(1+S/100))
stat          = (base + Σflat) · (1 + Σpct/100)         // % внутри категории складываются
tierMult      = [1, 1.75, 3.0, 5.2]
```

## Чек-лист баланса волны

- [ ] **Требуемый DPS** волны (`Σ HP врагов / таймер`) лежит в коридоре ±25% от DPS эталонной сборки (`tests/balance.spec.ts` печатает таблицу).
- [ ] TTK по ролям в целевых окнах: мясо 0.2–0.5 с, танк 2–3 с, элита 4–6 с, босс w10 25–35 с, w20 50–70 с.
- [ ] Время до смерти оператора «без движения в толпе» на эталонной сборке 4–8 с (игра требует движения, но прощает ошибку).
- [ ] В волне есть хотя бы одна угроза, заставляющая двигаться (раннер, минёр, ганнер), и не больше двух новых механик сразу.
- [ ] Новый тип врага впервые появляется *один* на волну раньше, чем станет массовым.
- [ ] Живых врагов ≤ 300 и вражеских снарядов ≤ 400 в пике (бюджет FPS).
- [ ] Последние 3 с волны без спавна, чтобы был шанс собрать скрап.

## Чек-лист баланса магазина и предмета

- [ ] Доход волны / средняя цена ≈ 1.2 (w1) → 1.9 (w5–15) → 2.5 (w20).
- [ ] У нового модуля «цена за эффект» (ΔDPS% или ΔEHP% на эталонной сборке w5/w10/w15, делённые на цену) не выходит за 50–150% медианы своей редкости. Ниже — мёртвый предмет, выше — обязательный.
- [ ] Сильный эффект идёт с компромиссом либо имеет капы или внутренний КД.
- [ ] On-trigger эффекты (onKill, onHit, onDash) имеют лимит рекурсии (глубина 1) и/или ICD.
- [ ] Стакание N копий даёт ≤ линейный рост (проверить N=5).
- [ ] Удача не единственный путь к эффекту. Без удачи легендарки всё равно появляются к w8+.
- [ ] Предмет попадает минимум в один тег-пул, чтобы у него была сборка.
- [ ] Текст: 1–2 строки, числа видны, ключевые слова из словаря `content/keywords.ts`.

## Добавление оружия

1. Определение в `src/content/weapons.ts`: id, теги, базовый урон, кулдаун, дальность, снаряд, звук, силуэт.
2. Посчитай DPS тира I. Ориентир для одиночной цели: 55–80 DPS на тире I (AoE и пробой: −20–35% к одиночному DPS).
3. Прогон `npm test -- balance`: оружие не выбивается из коридора своего класса.
4. Запиши строку в таблицу оружия в `DESIGN.md`.

## Анти-паттерны

- Экспонента там, где хватает кусочной линейной кривой.
- Мультипликативное стакание одного и того же модуля.
- Скрытые числа: игрок должен видеть дельту в магазине.
- Правка баланса без обновления тестов и таблиц.
