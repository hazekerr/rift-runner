# Скиллы проекта

| Скилл | Источник | Что даёт |
|---|---|---|
| `game-balance` | свой, по итогам `docs/research/` | Каноничные формулы RR, чек-листы баланса волны и магазина, процесс добавления оружия |
| `game-feel` | свой, по итогам `docs/research/03-game-feel.md` | Чек-лист сочности: хитстоп, тряска, фидбек, звук, читаемость, бюджет FPS |
| `game-development` | [sickn33/antigravity-awesome-skills](https://github.com/sickn33/antigravity-awesome-skills) (MIT) | Общие принципы: цикл, паттерны, бюджет кадра, ввод через действия |
| `web-games` | то же | Особенности браузера: аудио-анлок, PWA, оптимизация |
| `2d-games` | то же | 2D-камеры, коллизии, top-down паттерны |
| `game-design` | то же | Core loop, прогрессия, flow |

Сторонние скиллы перед установкой прочитаны целиком: это чистый markdown, без скриптов и сетевых вызовов (`risk: none`). Скопированы как есть.
